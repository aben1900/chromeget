# chromeget · 精彩摘录

一个 Windows Chrome 侧边栏扩展：收藏文字与提示词，下载视频、图集、文件和 Hugging Face 公开模型。

**[下载最新 Release](https://github.com/aben1900/chromeget/releases/latest)** · [详细使用说明](使用说明.md) · [权限与隐私](PRIVACY.md)

## 在另一台电脑安装

需要 **Windows 10/11 x64、Chrome 116 或更新版**。不需要预装 Node.js、Python 或 FFmpeg。

1. 在 Release 的 **Assets** 下载 `chromeget-v版本号-windows-x64-setup.zip`。不要选择 GitHub 自动生成的 Source code 压缩包。
2. 解压到长期保留的位置，例如 `D:\Apps\chromeget`。不要在压缩包里直接运行。
3. 双击根目录唯一入口 **开始使用.cmd**，打开图形化“安装与管理”窗口。点击“打开 Chrome 扩展页”，或在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压目录里的 **extension** 文件夹。
5. 复制“精彩摘录”卡片显示的扩展 ID，在管理窗口粘贴 ID、选择摘录保存位置，点击“安装并连接 Chrome”。
6. 首次安装会联网从上游官方发布地址下载固定版本的 Node.js、yt-dlp、aria2、FFmpeg，并验证 SHA-256。等待出现“安装完成”。网络中断可重新运行。
7. 点击 Chrome 扩展菜单，把“精彩摘录”固定到工具栏；打开后点击“重新检测”，检查实际连接与需要处理的项目。

安装包本身不包含第三方引擎二进制；首次安装需要访问 GitHub 和 nodejs.org。Chrome 扩展留在解压位置，本地程序安装到 `%LOCALAPPDATA%\JingcaiClipper`。**安装后不要删除或移动 extension 文件夹。** 每台电脑的扩展 ID 可能不同，请使用该电脑实际显示的 ID。

这是开发者模式安装包，不是 Chrome 网上应用店 CRX。受组织策略管理的 Chrome 可能禁止加载未打包扩展。本版本不支持 macOS、Linux 或 Windows ARM64。

## 一个入口即可

根目录只有 **开始使用.cmd**：它打开 Windows 原生图形窗口，不需要额外安装 GUI 框架。

- **开始使用**：加载扩展指引、扩展 ID、目录选择、安装与更新修复。
- **使用说明**：日常流程、功能介绍、下载最新版本。
- **高级选项**：引擎更新、便携模式、解除本地连接。

安装时显示实时日志和等待动画，窗口保持响应。旧版本的多个 CMD 已合并；如果覆盖解压后仍看到旧入口，只使用新的“开始使用.cmd”。开发者打包工具保留在 tools 中，不再作为用户入口。

## 从收集开始

打开侧栏的“收集”，粘贴文字或一个网址，预览后确认。文字可保存为内容、评论、评阅或提示词；提示词标题可编辑。网址可以只收藏地址，也可以进入视频、文件或模型的选择流程。多个网址可转到批量下载，仍需确认。右键“收集并预览”使用同一入口。已有用户保留当前功能页选择。

连接面板提供扩展 ID 复制、安装步骤与重新检测。管理中心的“检查本机环境”和“完整校验引擎”检查注册、目录和固定版本安装记录；本机检查通过不等于浏览器已连接，以侧栏真实通信结果为准。

错误卡提供与当前操作对应的恢复入口。删除任务仍保留文件；更换目录不会迁移原任务片段。遇到提交超时，先核对原任务或原记录，避免重新提交。

## 能做什么

- **内容摘录**：右键保存选中文字、网址、提示词；本地规则提炼标题，确认后保存。只使用 JSON，一次保存对应一条记录。
- **视频 / 图集**：解析源站实际可用画质，可选音频格式或图集中的部分图片；支持手动使用本浏览器对应站点登录态。
- **文件下载**：粘贴网址自动预览；Hugging Face 公开仓库列出文件供选择；支持 HTTP Range 并发、续传和可选 SHA-256 校验。
- **任务管理**：独立暂停、继续、删除、打开目录；筛选即时显示加载状态。关闭侧栏不停止后台下载。
- **网页辅助**：可选视频悬浮入口和当前标签页媒体捕获；是否能下载取决于网站、权限和资源格式。

并发最高 64 路，不代表所有服务器都会更快；不支持绕过 DRM，无法保证所有站点、付费画质或私有模型可用。

## 更新与卸载

更新前暂停下载任务、关闭侧栏。用新包覆盖原解压目录（不要删除个人文件），打开 **开始使用.cmd**，点击 **更新 / 修复**，再到 `chrome://extensions` 点击重新加载。安装脚本保留已有本地任务和设置；不要卸载 Chrome 扩展再装，以免丢失待保存记录。

卸载：先确认待保存记录已落盘，在 Chrome 移除扩展，再打开 **开始使用.cmd → 高级选项 → 解除本地连接（卸载）**。脚本只解除 Native Messaging 注册，保留程序、任务和个人文件；确认不再需要时再手动处理。

## 常见问题

- **Specified native messaging host not found**：先加载 extension，再打开开始使用.cmd 点击安装，填写这台电脑的扩展 ID；不要使用他人的 ID。
- **请更新本地程序 / 不支持的操作**：打开最新包中的开始使用.cmd，点击“更新 / 修复”，重新加载扩展，关闭旧侧栏后重新打开。
- **引擎下载失败或校验失败**：检查是否能访问提示的官方域名，再重试。不要通过关闭校验来继续安装。
- **只装了扩展却无法保存/下载**：还必须在开始使用.cmd 中完成安装，本地程序负责文件写入和后台下载。

## 开发与发布

源代码和用户数据隔离。`native/bin` 的第三方引擎、Cookie、任务记录、输出文件和 `work` 不进入 Git。

```powershell
# 下载校验开发所需引擎
powershell -NoProfile -ExecutionPolicy Bypass -File tools/prepare-engines.ps1
# 运行核心测试（需要 Windows PowerShell 5.1）
native/bin/node.exe tests/test.cjs
# 构建公开 Release 安装包和校验文件
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package.ps1 -PublicRelease
```

构建会同步 `功能介绍.html`。`tools/engines.lock.json` 固定下载地址和 SHA-256；变更引擎版本需重新验证安装与下载测试。新电脑安装流程在隔离目录测试，不代表每种 Windows/Chrome 策略组合都已验证。

## 资料库与导出（1.25.0）

点击侧栏“打开资料库”可搜索默认摘录及已完成下载，按类型、来源、标签、集合整理。详情支持完整正文复制、提示词 {{变量名}} 填写与本地 Markdown / ZIP 导出。导出前确认清单，缺失文件可选择跳过；单次最多 100 份资料、10000 个文件。原始 JSON 不迁移，资料库索引.json 保存整理信息。更新时需同时修复本地程序并重新加载扩展。

## 本地资料备份（1.26.0）

资料库 → 备份与恢复：创建 `.jingcai-backup.json`，预览后确认合并恢复。冲突保留当前内容，恢复前自动备份，支持中断回滚与结果核对。范围为摘录和资料索引，不含实际下载文件、Cookie、引擎及浏览器注册；最多 100 MiB、100000 条摘录。详见使用说明。

## 智能摘要（1.27.0）

打开侧栏的“资料库”，展开页面上方“智能摘要设置”。OpenAI / DeepSeek 的地址、模型及参数已经填写，只需填真实 API Key 并保存；示例 sk-placeholder-replace-me 不能使用。也可点击“读取 CC-Switch 配置”，选择 yqn Claude 及其模型，保存选择。重新打开页面如需 CC-Switch，主动读取配置后选择。

选择一条文字摘录，在详情下方点击“准备摘要”，核对服务域名、模型和字数，再点击“生成摘要”。结果可以编辑、复制和保存，原文保留。失败或超时先点击“核对结果”，不会自动重发收费请求。已有摘要需重新生成并保存才替换；原文变化时会提示过期。

支持最多 24000 Unicode 字符、96 KiB 的单条原文；不抓取 URL 网页，不解析下载文件，不含 OCR、音视频转写或迁移。摘要会发送到所选服务并使用 API 额度。尚未替用户验证真实密钥或线上服务可用性。

### 1.27.1 配置入口

OpenAI / DeepSeek 是独立个人 SK 配置。公司模型单独点击“公司模型”，直接引用 CC-Switch 现有服务与模型，无需 SK 或保存步骤；不会导入或覆盖个人 API。读取后在“使用模型”下拉框切换即可。配置完成后点击“去选择摘录”，文字资料卡上的“生成摘要”直达详情顶部的摘要面板。
