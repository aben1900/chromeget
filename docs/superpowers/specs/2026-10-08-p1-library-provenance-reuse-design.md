# P1：统一资料库、来源与去重、复用与导出

日期：2026-10-08
状态：用户已确认；1.25.0 已实现并验证，见 ../plans/2026-10-08-p1-library.md。

## 目标与既有依据

用户要求 P0 完成后继续原先建议的三项 P1：统一资料库、来源与去重、复用与导出。目标是个人用户保存后能找回、核对来源并用于工作。P0 验收见 plans/p0-progress.md；本轮重新运行 connection、collect、recovery、collect-ui、recovery-ui 五项测试均通过。

保留一个 Chrome 扩展及“开始使用.cmd”入口。资料留在本机；保持原有 JSON、任务管理和下载确认流程。此前帮助页窄屏修复保留，不覆盖未提交改动。

## 方案与取舍

采用独立资料库页面，加本地统一查询和附属整理数据。侧栏只增加“打开资料库”入口，避免挤占快速收集空间。摘录 JSON 和下载记录继续作为事实来源；标签、集合与下载资料快照单独持久化，不把频繁变化的任务状态写回摘录文件。

仅在现有摘录页加搜索无法覆盖下载资料；直接迁移到数据库会引入运行依赖和数据迁移风险。本轮采用渐进方案，后续数据量需要时再迁移索引。搜索范围明确为记录文字及文件元信息，不宣称能搜索视频语音、图片文字或任意文件正文。

## 一、统一资料库

- 独立扩展标签页提供搜索、类型、来源站点、标签、集合筛选，按保存时间排序及分页。筛选在完整数据范围执行，不能只过滤当前一页。
- 汇总当前默认摘录文件，以及本扩展下载的已完成视频、音频、图集、普通文件和模型资料。进行中的任务仍在下载页查看。多文件下载按一份资料分组，详情列出具体文件。
- 列表展示标题、类型、保存时间、来源、标签、集合及文件状态。详情可复制摘录、访问来源、定位目录、编辑整理信息。旧摘录页面的外部 JSON 查看保持独立，不悄悄并入默认资料库。
- 标签为多选；每条资料可加入多个集合。支持新建、重命名、删除标签/集合，删除整理分类只移除关联，不删除摘录或下载文件。批量整理只作用于明确勾选项，翻页或更改筛选清空选择。
- 本轮资料库不增加“删除本地文件”操作。下载文件缺失或移动时显示明确状态，不把过往下载完成等同于文件仍然存在。
- 空库、无搜索结果、断连、旧宿主、部分任务记录损坏均提供不同提示。部分读取失败明确显示范围，不能将不完整结果显示为全部资料。
- 键盘可完成筛选、选择和详情操作；320/390/600/900/1440 像素下布局可用。较窄窗口详情改为纵向，较宽窗口可并排显示。

## 二、来源与去重

摘录新增可选 sourceUrl、sourceTitle、author 字段。右键或“使用当前网页”时记录真实页面地址与标题；粘贴文字不推断来源。作者仅使用解析器明确提供的值或用户填写内容，未知时不编造。旧记录缺失字段仍能读取和编辑整理信息，无须批量改写原 JSON。

来源链接只接受 HTTP/HTTPS，拒绝凭据 URL；不把媒体临时签名下载地址当作公开来源。日志、错误和默认导出不泄露授权参数。来源显示与实际下载请求分开存储，下载请求不受整理功能改写。

重复提示使用确定规则：文字先统一换行和首尾空白再比较完整正文；网址仅规范化协议/主机大小写及默认端口，保留有意义的查询参数与片段，不猜测两个不同 URL 等价。内容相同可提示重复，类型不同仍允许单独保存。下载沿用既有任务去重逻辑，资料库仅展示关联结果，不发起额外下载。

统一收集确认前提示已有记录，提供“查看已有”“仍然保存”。旧右键快捷保存保留直接保存习惯，保存后提示存在相同资料并提供资料库入口，不静默丢弃用户的再次保存。网络失败、待保存队列和重试继续沿用原 ID 幂等保障，内容去重与提交幂等分开处理。

## 三、复用与导出

- 摘录详情一键复制完整正文；失败提示用户手动复制，不误报成功。
- 提示词支持 {{变量名}} 占位符，相同名称只填写一次。填值后展示完整预览并复制，不执行模板代码、不联网调用 AI、不改写保存的模板；未填项需提示后才能复制。
- 勾选资料导出 UTF-8 Markdown，含标题、类型、保存时间、可公开来源、作者、标签与集合。摘录包含完整内容，下载资料包含文件清单和相对路径。对 Markdown 链接与代码围栏安全转义。
- 项目资料包 ZIP 包含 Markdown 索引、结构化清单、所选摘录和用户确认包含的已完成本地文件。准备阶段展示数量、总大小、缺失项和导出位置；用户确认后开始，不自动上传。
- 缺失文件由用户选择取消或跳过，跳过项记录在清单，不生成“完整导出”的虚假提示。导出不覆盖现有文件，使用临时文件完成后原子命名；失败清理本次临时产物。大文件逐流处理，不通过 Native Messaging 传输文件或 ZIP 字节。
- 路径来自经过验证的资料记录，界面只提交资料 ID。拒绝路径穿越、符号链接/重解析点逃逸，不包含 Cookie、配置、日志和未选中的目录内容。导出与下载并行时只打包已完成且仍匹配记录的文件。

## 本地数据与接口

新增 native/library.ps1 管理统一查询、整理信息、去重和导出，host.ps1 只增加明确动作分发与能力标识。整理数据存放在配置的资料目录内独立文件，具有 schemaVersion；原子写入并使用目录级互斥。旧数据不自动迁移、不删除。

资料 ID 使用类型命名空间，摘录绑定现有 UUID，下载绑定现有任务 ID。首次索引只读导入已有完成任务；新增完成任务的资料快照在任务删除前持久化，删除下载历史不会丢失已建立的整理信息。索引更新可重试且幂等，损坏索引不能覆盖源数据。实现中需专门验证快照与任务删除的竞态。

接口按职责分为 library-query、library-read、library-update、library-taxonomy、library-duplicates、library-export-prepare、library-export-start、library-export-status，以及受限的目录定位。查询返回摘要和分页游标；大正文分块读取。导出准备生成有期限的本机计划 ID，开始时重新验证文件和目的地，返回任务 ID供状态查询。禁止直接接受任意 shell 命令或浏览器指定的源路径。

background 对来源页面执行严格白名单校验，library.html 才能调用整理和导出接口；来源采集沿用可信收集消息。网页内容脚本不能访问资料库文件接口。新旧宿主通过 capability 区分，旧宿主提示管理中心更新，不回退成未知动作重试。

新增扩展 library.html/css/js 和可测试的纯搜索/模板/格式化模块。同步更新安装、修复、便携和打包文件清单。目标版本为扩展与本地程序 1.25.0；功能完成验证后才升级版本与用户文档。

## 实施顺序与验收

1. 来源可选字段、数据兼容、资料身份和本地整理存储；验证旧 JSON、未知字段保留、原子写入、并发修改及损坏文件保护。
2. 完成任务资料快照与统一查询；验证历史导入、重复索引、任务删除、文件移动、跨页搜索与筛选组合。
3. 独立资料库、标签与集合；验证键盘操作、窄屏、状态隔离、取消选择、旧宿主与断连提示。
4. 来源显示与重复确认；验证换行等价、不同查询参数、重复但仍然保存、直接右键、队列重试和多窗口竞态。
5. 复制、变量预览、Markdown 与项目 ZIP；验证中文、超长正文、代码围栏、空变量、磁盘不足、缺失文件、路径逃逸、大文件与导出失败清理。
6. 运行 P0 与下载回归，更新 showcase/features.json、使用说明.md、README/PRIVACY，并生成帮助页。按公开包规则构建本地 ZIP，在临时目录 SkipRegistration 检查安装及升级保留资料；不自动发布 GitHub。

验收场景：保存一段带来源的提示词与一份下载资料；在资料库全文搜索找到它们，加入同一集合；再次保存时能查看已有或保留新记录；填写变量复制；导出含索引和所选文件的 ZIP。关闭重开后整理信息仍在，旧摘录可正常读取，原下载任务照常运行。

## 自检

三项 P1 均有具体流程、存储边界和验收场景；本轮不加入云同步、OCR、全文文件解析或自动作者推断。保留真实来源和旧记录兼容，区分任务历史与资料快照、重复提示与提交幂等、Markdown 清单与实际文件打包。实现计划需细化导出资源上限、分页游标一致性和快照写入时序，再开始产品代码变更。
