    安装、更新与修复
    第一次安装
    1. 解压安装包，打开“开始使用.cmd”。
    2. 在 Chrome 扩展管理页开启“开发者模式”，点击“加载已解压的扩展程序”，选择包内 extension 文件夹。已能看到本页则说明这一步已完成。
    3. 复制下面的安装识别码，粘贴到管理窗口的“扩展 ID”，选择保存目录，点击“安装并连接 Chrome”（已安装时显示“应用设置 / 重新安装”）。
    4. 安装完成后回到这里，点击“检查是否可以使用”。

    已安装，更新或修复
    1. 将新版安装包解压并覆盖原来的安装包目录，保留 Chrome 已加载的 extension 文件夹路径。打开新版安装包里的“开始使用.cmd”，点击“更新 / 修复”。正常更新无需重新填写识别码。
    2. 打开 Chrome 扩展管理页，找到“精彩摘录”，点击卡片上的圆形箭头 ↻，让 Chrome 读取更新后的扩展文件。
    3. 重新打开侧栏，点击“检查是否可以使用”，查看上方结论。
