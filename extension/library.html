模型管理备份与恢复功能入口与操作说明
功能入口与操作说明 · P2 进度

已实现

智能摘要：打开“模型管理”→ 添加或导入模型 → 测试连接 → 保存 → 设为默认。在文字资料卡点击“生成摘要”→ 准备摘要 → 核对目标 → 生成 → 复制或保存。首次打开自动导入本机 WorkBuddy 的 SMEC 配置；也可从 CC-Switch 导入。

本地备份：展开“备份与恢复”→ 创建本地备份。文件写入资料目录的“备份”文件夹；在“已有本地备份”中查看并打开目录。

恢复备份：备份与恢复 → 选择备份文件 → 查看新增与冲突预览 → 确认合并恢复。冲突保留当前内容，恢复前自动备份。备份包含已保存摘要与资料索引，不含实际下载文件、SK 或 Cookie。

尚未开发，可选择下一项

  • 图片 OCR：从图片提取文字，形成可检索、可摘要的内容。
  • 音视频转写：把音频或视频语音转成文字，再整理与摘要。
  • 相似资料关联：识别主题相近的资料，推荐关联；现有完全重复提示不等于此功能。
  • 新电脑迁移：迁移资料、下载文件并处理路径映射；按你的要求暂缓。

以上待开发项目没有可用入口。资料搜索、标签/集合、来源、提示词变量、Markdown/ZIP 导出属于已完成 P1，不计为新增 P2。

模型标签连接状态操作

重新加载后重新打开资料库，未保存的内容需要重新填写。

如何使用

为一个已配置模型点击“设为默认”，然后在文字资料卡点击“生成摘要”。核对模型和原文后发送，结果可编辑、复制或保存。

模型配置在本机加密保存。测试仅发送固定短消息，会产生少量 API 用量。导入不会自动调用模型生成内容。

添加模型

最多 10 个标签，每个 24 字。标签仅用于本机整理，不发送给模型。

导入模型

导入后可独立编辑。已有配置不会因重复导入而增加；手动修改项需要明确勾选才会覆盖。
最近导出（最多 10 项）

备份与恢复

备份摘录、来源、标签、集合与下载资料索引，不包含实际下载文件。仅恢复本扩展的专用备份，最多 100 MiB、100000 条摘录。

备份包含私人原文和路径，请勿公开上传。建议复制到另一磁盘；同一磁盘上的备份不能抵御磁盘损坏。

确认恢复范围

相同内容跳过；同编号冲突保留当前内容。标签与集合合并。下载仅恢复元信息和原路径，文件缺失时不会重新下载。

查看冲突摘要（最多 50 项）

    确认后先自动备份当前资料，再合并恢复。预览 15 分钟有效；期间资料有变化须重新预览。
