A SIMPLE WORKFLOW

选中、确认，然后安心交给后台。

01 / 发现内容

从当前网页开始

选中文字右键收藏，或把视频、图片与文件链接载入侧边栏。悬浮按钮与媒体发现协助找到资源。

02 / 确认选择

按自己的需要保存

修改提示词标题，选择视频画质、音频格式、图集图片或模型文件，再确认保存目录。

03 / 本地管理

看进度，也能继续处理别的事

在侧边栏查阅摘录，管理下载队列。每个任务可单独暂停、继续、删除或打开目录。

READY ON YOUR DESKTOP

从浏览器，到你的本地文件。

Windows 10/11 x64 · Chrome 116 或更新版本

下载 GitHub Release ↓

下载 Assets 中的 windows-x64-setup.zip；首次安装联网下载并校验引擎。

  1. 打开 chrome://extensions，启用开发者模式。
  2. 加载本项目的 extension 文件夹。
  3. 打开“开始使用.cmd”，在图形窗口填写扩展 ID 与保存目录并安装。
  4. 打开扩展侧边栏，即可收藏或下载。

便携使用：打开管理窗口的“高级选项”。Chrome 仍需一次本机注册；移动目录后重新注册。
